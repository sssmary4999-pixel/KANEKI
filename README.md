# KANEKI BOT

بوت واتساب عربي (Baileys) — 3 ملفات فقط: `index.js` (الاتصال والمعالجة) · `commands.js` (كل الأوامر) · `lib.js` (الخطوط وقاعدة البيانات).

## التشغيل
- Build: `npm install` — Start: `npm start` — Node 20+
- متغيرات البيئة: `PHONE_NUMBER` (رقم البوت بمفتاح الدولة بلا +) · `OWNER_NUMBER` (أرقام المالكين مفصولة بفاصلة)
- للحفظ الدائم (Render Disk على `/var/data`): `SESSION_DIR=/var/data/session` و`BOT_DB_PATH=/var/data/db.json`
- شاهد Logs واكتب كود الاقتران في واتساب ← الأجهزة المرتبطة.

## إضافة أمر
في `commands.js` أضف سطراً: `add('ترفيه', 'اسم alias', 'الوصف', c => c.reply('...'))` — يظهر تلقائياً في `.اوامر`.
خيارات: `{group:true}` · `{admin:true}` · `{owner:true}`.

## الخطوط
`.خط` يعرض 6 أنماط، و`.خط 3` يغيّرها. الأنماط تعمل على الحروف اللاتينية؛ الحروف العربية ليس لها أنماط في Unicode، فاستُخدمت الإطارات ومدّ الحروف (`.زخرفة`).
